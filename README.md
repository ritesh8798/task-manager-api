# Task Manager API

## Features
- User Authentication (JWT)
- CRUD Operations
- MongoDB Database
- Middleware
- Error Handling
- Postman Tested
- Render Deployment

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Postman
- Render

## API Endpoints
- POST /register
- POST /login
- GET /tasks
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id

- https://task-manager-api-3l2y.onrender.com

npm install
npm start
